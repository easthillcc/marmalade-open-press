# Code of conduct

Marmalade Open Press, made by [Marmalade](https://marmalade.family).

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). Be kind about people and exacting about files.

To report behaviour that breaks it, use [GitHub's private reporting](https://github.com/easthillcc/marmalade-open-press/security/advisories/new) and say it is a conduct report, or contact the maintainers through the [Marmalade website](https://marmalade.family). Reports are read by the maintainers only and kept confidential.
